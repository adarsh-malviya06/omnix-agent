# OMNIX Agent Architecture & System Documentation

This directory contains technical documentation, system architecture specifications, and API guides for OMNIX Agent.

- Architecture: Supervisor-based Multi-Agent Platform (LangGraph)
- Persistence: SQLite / SQLAlchemy ORM
- Intelligence: Scikit-learn (ML Forecasting) & ChromaDB (RAG)
- Interfaces: FastAPI (REST) & Streamlit (Enterprise Dashboard)
